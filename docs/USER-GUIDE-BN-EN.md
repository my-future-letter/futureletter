# My Future Letter — User Guide

## বাংলা
### চিঠি কীভাবে লিখবেন
1. **Write a Letter** চাপুন।
2. Google দিয়ে sign in করুন।
3. আপনার username তৈরি করুন।
4. একটি template বেছে নিন, অথবা সরাসরি নিজের মতো লিখুন।
5. চাইলে আপনার ছবি যোগ করুন।
6. ভবিষ্যতের তারিখ নির্বাচন করুন।
7. একটি আলাদা **Letter Password** দিন।
8. **Save Draft** বা **Seal & Publish** চাপুন।

### চিঠি পরে কীভাবে খুলবেন
আপনার public link খুলুন → password দিন → **Unlock Letter** চাপুন।

### PDF কীভাবে রাখবেন
চিঠি প্রকাশ করার পর আপনার dashboard থেকে PDF তৈরি/সংরক্ষণের workflow ব্যবহার করুন। PDF-টি ফোনে Downloads/Files-এ রাখুন এবং চাইলে Google Drive, cloud storage বা গুরুত্বপূর্ণ কাগজপত্রের সঙ্গে সংরক্ষণ করুন। PDF-এর QR code ভবিষ্যতে public letter page খুলতে সাহায্য করবে।

### গুরুত্বপূর্ণ
- এক account-এ সর্বোচ্চ ৫টি letter।
- এক account-এ সর্বোচ্চ ২৫টি photo।
- Letter password ভুলে গেলে website থেকে সেটি recover করা যাবে না।
- Google account password এবং Letter password আলাদা।

## English
### How to create a letter
1. Tap **Write a Letter**.
2. Sign in with Google.
3. Create your unique username.
4. Choose a template or start from a blank page.
5. Add photos if you want.
6. Choose the future date.
7. Create a separate **Letter Password**.
8. Tap **Save Draft** or **Seal & Publish**.

### How to open it later
Open your public link → enter the letter password → tap **Unlock Letter**.

### How to keep the PDF
After publishing, use the PDF download option from your dashboard/workflow. Keep the PDF in your phone's Files/Downloads folder, Google Drive, another cloud backup, or with your important physical documents. The PDF contains a QR code that can help you return to the public letter page later.

### Important
- Maximum 5 letters per account.
- Maximum 25 photos per account.
- A forgotten Letter Password cannot be recovered by the website.
- Your Google password and Letter Password are separate.
